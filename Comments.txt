Singleton (Одиночка) - Паттерн, который гарантирует, что у класса будет только ОДИН экземпляр.

Proxy — это объект-обёртка, который позволяет перехватывать действия с другим объектом.

  Суть:
  - есть target (оригинальный объект)
  - есть handler (ловушки / traps)
  - Proxy перехватывает операции (get, set и др.)
 
  Зачем:
  - валидация данных
  - логирование
  - реактивность (как в Vue)
  - контроль доступа
